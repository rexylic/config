My configuration files.
These files should be enough to set up a new system to my liking.

----------------

Install the following manually:

- [`fish`](https://fishshell.com)
- [`nanobrew`](https://github.com/justrach/nanobrew#install)
- [`mise`](https://mise.jdx.dev/)
- [`helix`](https://docs.helix-editor.com/building-from-source.html)

then run `mise bootstrap` for language environments and use `nanobrew` to install rest of the packages listed in [`nanobrew/bundle`](nanobrew/bundle).
